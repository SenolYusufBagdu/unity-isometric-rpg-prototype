# 🎮 Unity Isometric RPG Prototype

This is a solo-developed isometric action RPG prototype built with Unity.

---

## 🚀 Features

* Player movement & rotation system
* Melee combo and magic system
* Right-click aiming system
* NavMesh-based enemy AI
* Dash & i-frame mechanics
* World-space health bars
* 🌙 **Dynamic Day & Night Cycle (NEW)**
* ⚔️ **Time-based enemy aggression (enemies are stronger at night)**

---

## 🌙 Day & Night System (New)

A dynamic day-night cycle system has been implemented to enhance immersion and gameplay difficulty.

### ✨ Highlights

* 🌌 Smooth transition between day and night
* 🎨 Main Camera background dynamically updated (`#050819` for night tone)
* 🔄 `DayNightCycle.cs` updates lighting every frame
* ⚔️ Enemies become more aggressive during nighttime
* 🎮 Adds dynamic difficulty based on time of day

### 🛠 Technical Details

* Real-time camera background color interpolation
* Frame-based update system for smooth transitions
* Enemy behavior linked to time state (day/night)

---

## 🧠 Core Idea

Build your village during the day, survive waves of enemies at night.
